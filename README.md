## 🚀 Getting Started
1. Clone the repository:
-> git clone https://github.com/Diptesh-coder/My-Portfolio.git
->cd My-Portfolio

3. Install the dependencies:
  .> npm install

4. Run the development server:
-> npm run dev

5. Build for production:
-> npm run build
